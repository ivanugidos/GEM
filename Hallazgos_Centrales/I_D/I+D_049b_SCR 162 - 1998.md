# 12. Instrumentación sin contaminación

Esto es esencial.

No conectar directamente osciloscopio o multímetro estándar a la unión del Diodo Escalar si se busca una señal escalar de alta impedancia.

Estrategia:

1. **Buffer de alta impedancia:**

$$
Z_{\text{in}} > 10^{12}\ \Omega
$$

2. **Aislamiento galvánico:**

- transformador de señal,
- acoplador óptico,
- acoplador capacitivo de alto voltaje.

3. **Lock-in a 16.2 Hz:**

Solo si primero aparecen firmas térmicas o inerciales.

4. **Sensores térmicos aislados:**

- termistor NTC de precisión,
- fibra óptica si es posible,
- sin contacto eléctrico con la unión activa.

5. **Referencia térmica gemela:**

Un sensor idéntico fuera del campo activo para restar deriva ambiental.

### 🐍 2. Entrega 1: Script Python (Generador de Geometría Temporal)

Este script genera el archivo `.csv` exacto que ngspice o LTspice necesitan para inyectar la envolvente SCR-1998 como una fuente `PWL` (Piecewise Linear).

```python
"""
GEM I+D-162 SCR: Generador de Envolvente Temporal SCR-1998
Genera un archivo PWL para SPICE y un header para Firmware.
"""
import csv

# Secuencia SCR-1998 (en milisegundos)
seq_ms = [126, 162, 216, 261, 612, 621]
# Amplitudes normalizadas (respecto al pico máximo 621)
seq_amp = [126/621, 162/621, 216/621, 261/621, 612/621, 621/621]

t_total = sum(seq_ms) # 1998 ms
cycles = 5 # Repetir el ciclo 5 veces para simulación (casi 10 segundos)

# Archivo para SPICE (PWL)
with open('scr1998_envelope.csv', 'w', newline='') as f:
    writer = csv.writer(f)
    t_current = 0.0
    eps = 1e-6 # Pequeño epsilon para evitar líneas verticales infinitas en SPICE
    
    for cycle in range(cycles):
        for i in range(len(seq_ms)):
            # Inicio del segmento
            writer.writerow([f"{t_current:.6f}", f"{seq_amp[i]:.6f}"])
            # Fin del segmento (menos epsilon)
            t_end = t_current + seq_ms[i] - eps
            writer.writerow([f"{t_end:.6f}", f"{seq_amp[i]:.6f}"])
            t_current += seq_ms[i]
            
    # Cierre a cero
    writer.writerow([f"{t_current:.6f}", "0.000000"])

print("✅ Archivo 'scr1998_envelope.csv' generado para ngspice/LTspice.")
```

### 🧠 4. Entrega 3: Firmware Base (C++ para Teensy / Arduino)

Para el banco físico, no usaremos SPICE. Usaremos un microcontrolador para modular físicamente la puerta. El Teensy es ideal por sus DACs de alta velocidad y timers precisos.

```cpp
/*
 * GEM I+D-162 SCR: Generador de Hardware para Banco Físico
 * Salida: DAC (0-3.3V) hacia un VCA (Voltage Controlled Amplifier) 
 * o multiplicador analógico (ej. AD633) que module la señal de 16.2 Hz.
 */

const int PIN_DAC = A14; // Pin DAC en Teensy
const unsigned long seq_ms[6] = {126, 162, 216, 261, 612, 621};
const float seq_amp[6] = {0.2029, 0.2609, 0.3478, 0.4203, 0.9855, 1.0000};

unsigned long cycleStart = 0;

void setup() {
  analogWriteResolution(12); // 12 bits (0-4095) para mayor suavidad escalar
  cycleStart = millis();
}

void loop() {
  unsigned long t = (millis() - cycleStart) % 1998; // Tiempo en el ciclo SCR
  
  // Determinar en qué segmento de la secuencia estamos
  unsigned long accumulated = 0;
  for (int i = 0; i < 6; i++) {
    accumulated += seq_ms[i];
    if (t < accumulated) {
      // Aplicar la amplitud de este segmento al DAC
      int dacValue = (int)(seq_amp[i] * 4095.0);
      analogWrite(PIN_DAC, dacValue);
      break;
    }
  }
}
```
*Nota de Ingeniería:* Esta señal DC escalonada (la envolvente) debe pasar por un filtro paso bajo RC suave (ej. $R=10k\Omega, C=1\mu F$) antes de entrar al multiplicador analógico, para que la transición entre los números no genere armónicos de alta frecuencia que ensucien la nulificación vectorial.
